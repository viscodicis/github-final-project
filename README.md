# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- `p`: Principal amount
- `r`: Annual rate of interest (percentage)
- `t`: Time period in years

## Usage

Run the `simple-interest.sh` Bash script. Enter the principal amount, annual interest rate, and time period when prompted.

## Output

The calculator displays the simple interest calculated from the supplied values.
